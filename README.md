# The universal square-root-of-six bound for kissing numbers

This project proves in Lean 4 / Mathlib that

\[
\tau_n \le (\sqrt 6)^n \qquad(n\ge1),
\]

and that **√6 is the least possible base** in a bound of the form \(\tau_n\le\alpha^n\) required in every positive dimension, without a prefactor. This is a uniform bound, not a claim of asymptotic optimality.

The certificate is unconditional: the main configuration theorem assumes only that the vectors have norm one and distinct vectors have inner product at most `1/2`. The proof establishes the geometric packing inequalities and all dimension cases. It constructs the kissing number as an attained greatest cardinality, and an explicit regular hexagon proves `kissingNumber 2 = 6`.

## Verify the certificate

The project pins Lean `v4.33.1` and Mathlib commit
`0df444a360eaa60ab8c11dca51a86af692955474`.
With Lean's `elan` installer available, run from this directory:

```bash
lake exe cache get
bash scripts/check.sh
```

The first command downloads the pinned Mathlib build cache. The second builds every imported project module, scans for proof holes and project-defined axioms, checks the main statements with exactly their geometric hypotheses, and rejects any project declaration whose axiom dependencies exceed `propext`, `Classical.choice`, and `Quot.sound`.

The normal [Lean CI workflow](.github/workflows/lean.yml) runs on pull requests with read-only repository permissions. Its check on the exact commit is authoritative; historical development diagnostics are not certificates. Source hashes are listed in `SOURCE_SHA256SUMS`.
